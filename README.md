# 🧩 LEETCODE_DSA

Solving DSA problems on LeetCode in **Python/C++**, tracking patterns, approaches, and progress as part of daily CP practice.

## 📖 About

This repository holds my solutions to LeetCode problems along with notes on the patterns and approaches behind them. The goal is to understand *why* a solution works, not just to get it accepted.

## 📁 Structure

```
LEETCODE_DSA/
├── python/      # Python solutions
├── cpp/         # C++ solutions
├── notes/       # Pattern and approach notes
├── tracker.md   # Problem tracker
└── README.md
```

## 🗂️ Solution Format

Every solution file starts with a short header:

```python
# LC <number> - <title>
# Difficulty: Easy | Medium | Hard
# Pattern: <e.g. Sliding Window>
# Time: O(?) | Space: O(?)
# Approach: <one-line idea>
```

## 🧠 Topics

- Linked Lists

- Recursion and Backtracking
- Dynamic Programming

## 📈 Progress

Progress is tracked in [`tracker.md`](tracker.md), with the problem number, difficulty, pattern, and status for each problem.

## 🔁 Workflow

1. Attempt the problem on my own first
2. Write the solution in Python or C++
3. Record the pattern, complexity, and key insight
4. Revisit tricky problems after a few days
